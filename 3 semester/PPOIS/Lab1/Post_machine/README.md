# Лабораторная работа №1: Машина Поста (`PostMachine`)

Реализация лабораторной работы №1 по курсу **«Проектирование программного обеспечения интеллектуальных систем» (ППОИС)** на языке **C++ (C++17)**.  
**Вариант:** `1.8 Абстрактные машины` / `1.8.1 Машина Поста`.

## Архитектура проекта (4 класса)

Согласно требованиям варианта 1.8 (не менее трёх классов), система спроектирована из **четырёх независимых классов**, разделённых на заголовочные файлы (`include/*.h`) и файлы реализации (`src/*.cpp`):

1. **`PostTape` (`include/PostTape.h`, `src/PostTape.cpp`) — Лента и каретка**:
   - Бесконечная в обе стороны двоичная лента (`0` — пусто, `1` — метка) на базе динамического массива (`new bool[]` / `delete[]`), автоматически расширяющегося при движении каретки влево или вправо;
   - Перемещение каретки пре- и постинкрементом (`++tape`, `tape++`) и пре- и постдекрементом (`--tape`, `tape--`);
   - Задание и изменение значений на ленте (`mark()`, `erase()`, `setCell()`, `operator[]`), загрузка состояния из потока (`operator>>`) и вывод (`operator<<`) с `mutable`-кэшированием.
2. **`PostRule` (`include/PostRule.h`, `src/PostRule.cpp`) — Правило (команда) машины Поста**:
   - Команды: `V` (поставить метку), `X` (стереть метку), `>` (каретка вправо), `<` (каретка влево), `? j1, j2` (переход по `0` к `j1`, по `1` к `j2`), `!` (останов);
   - Разбор правил из строки (`fromString`), валидация переходов, потоковые операторы `<<` и `>>`.
3. **`PostProgram` (`include/PostProgram.h`, `src/PostProgram.cpp`) — Программа машины Поста**:
   - Динамический массив правил (`new PostRule[]` / `delete[]`), упорядоченный по номеру правила;
   - Добавление (`addRule`, `operator+=`), удаление (`removeRule`, `operator-=`), просмотр и доступ по номеру (`getRule`, `operator[]`), загрузка программы из потока (`loadFromStream`, `operator>>`).
4. **`PostMachine` (`include/PostMachine.h`, `src/PostMachine.cpp`) — Абстрактная машина Поста**:
   - Объединяет ленту и программу, хранит текущее правило и счётчик шагов;
   - Выполнение одного шага (`step()`, `++machine`, `machine++`) и интерпретация всей программы (`run()`);
   - Загрузка начального состояния и программы из файла (`loadFromFile`) или потока (`operator>>`) и пошаговое логирование с флагом `-log`.

## Сборка и запуск

```bash
# Сборка приложения и запуск всех 31 модульного теста UnitTest++
make all

# 1. Запуск в режиме командной строки (по заданию п. 1.8) с флагом -log:
./build/post_machine_app examples/increment_unary.txt -log

# 2. Запуск в интерактивном режиме с консольным меню:
./build/post_machine_app

# Замер покрытия кода тестами через gcov (> 96%):
make coverage

# Генерация документации Doxygen:
make docs
```
