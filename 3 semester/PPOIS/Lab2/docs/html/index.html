Лабораторная работа №2: Информационная система «Музей» Doxygen 1.9.8

Объектно-ориентированная модель предметной области «Музей» (Museum) на языке C++17.

Сводная статистика модели

  • Доменных классов: 52 (плюс 13 собственных классов исключений = 65 классов)
  • Полей: 259
  • Содержательных методов (поведений): 175 (не считая геттеров и сеттеров)
  • Межклассовых ассоциаций: 76
  • Модульных тестов (UnitTest++): 32 (покрытие > 95%)
