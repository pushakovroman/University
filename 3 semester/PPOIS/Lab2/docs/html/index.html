Применение принципов ООП и паттернов проектирования

В проекте реализованы фундаментальные принципы объектно-ориентированной архитектуры:

🔒 1. Инкапсуляция

Все 259 полей данных строго закрыты спецификатором private:. Изменение состояния доступно исключительно через проверенные семантические методы с валидацией инвариантов.

🧬 2. Наследование

Разветвлённые иерархии: артефакты (Artifact → Painting, Sculpture, AncientManuscript, ArcheologicalFind), сотрудники (Employee → 4 специализации) и 13 классов исключений.

⚡ 3. Полиморфизм

Динамический полиморфизм через таблицы виртуальных функций (vtable): виртуальные деструкторы, переопределение calculateInsurancePremium() и расчёта зарплат calculateMonthlySalary().

🏛️ 4. Паттерн Facade

Класс Museum выступает единой точкой координации между всеми подсистемами, предоставляя высокоуровневый удобный интерфейс для оператора или внешних служб.

Руководство по кроссплатформенной сборке и запуску

Сборка выполняется без привязки к конкретной машине с помощью стандартного инструментария CMake и C++17 компилятора.

Terminal (Universal CMake Build) 
# 1. Перейдите в каталог лабораторной работы
cd "3 semester/PPOIS/Lab2"

# 2. Генерация файлов решения CMake (создаст папку build)
cmake -S . -B build

# 3. Сборка всех компонентов в оптимизированной конфигурации Release
cmake --build build --config Release

# 4. Запуск полного набора модульных тестов:
# На Windows (PowerShell / CMD):
.\build\Release\museum_tests.exe
# На Linux / macOS:
./build/museum_tests

# 5. Запуск интерактивного консольного приложения «Музей»:
# На Windows (PowerShell / CMD):
.\build\Release\museum_app.exe
# На Linux / macOS:
./build/museum_app
💡
Совет для пользователей Windows: Если в консоли PowerShell символы кириллицы отображаются некорректно, перед запуском введите команду chcp 65001.
